# Contribution

Les conventions d'outillage de ce depot sont formalisees dans le fichier racine
`CONTRIBUTING.md`.

Elles couvrent notamment :

- `uv` pour la gestion des dependances et l'execution
- `ruff` et `pyright` pour la qualite de code
- `bandit`, `pip-audit`, `pytest`, `pre-commit`
- `mkdocs` pour la documentation
- une CI GitHub Actions dediee dans `.github/workflows/ci.yml`
